LinuxVM guest tools 0.2.1 for Ubuntu 26.04 Desktop (GNOME Shell 50)

Open a terminal in this disc's folder and run:
  sh install.sh

An internet connection may be needed for Ubuntu package dependencies.
Log out and back in after installation to load the clipboard extension.

Includes clipboard text/PNG, Mac audio endpoints, host time zone following,
optional Mac shared folder, and virtual touchpad defaults.
The shared folder link never replaces an existing file or directory.
Changing the guest time zone stops automatic host following, across reboots.
