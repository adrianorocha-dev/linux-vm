LinuxVM guest tools 0.3.0 for Ubuntu 26.04 and Fedora, with GNOME or KDE Plasma

In KDE Plasma, click this disc in Dolphin to open it first.
Open a terminal in this disc's folder and run:
  sh install.sh

Packages: linuxvm-guest_<version>_all.deb (Ubuntu) and
linuxvm-guest-<version>-1.noarch.rpm (Fedora).
An internet connection may be needed for package dependencies.
Log out and back in after installation to start the clipboard and guest services.

Includes clipboard text/PNG, Mac audio endpoints, host time zone following,
optional Mac shared folder, virtual touchpad defaults, and on KDE Plasma a power
button that shuts Linux down.
The shared folder link never replaces an existing file or directory.
Changing the guest time zone stops automatic host following, across reboots.
