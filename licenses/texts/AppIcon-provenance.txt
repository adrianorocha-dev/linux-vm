AppIcon provenance — unresolved license

The checked-in AppIcon.icns is generated by scripts/render-icon.swift.
That script uses NSImage(systemSymbolName: "chevron.right", ...).
The SF Symbols release and glyph source bytes used for this render are not
recorded in the repository. No matching Apple license text is supplied.
The remaining artwork and rendering code are original Linux VM work with
no selected license. This file is provenance evidence, not a license grant.

Apple describes restrictions on SF Symbols in app icons at:
https://developer.apple.com/design/human-interface-guidelines/sf-symbols
Replace the symbol-derived artwork or establish permission before release.
