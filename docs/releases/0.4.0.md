# Linux VM 0.4.0

This release makes it harder for software in Linux, including malware, to reach your Mac.

- **QEMU runs in a macOS sandbox.** If a program in Linux ever broke out of QEMU, it could change only the VM's own files. It couldn't read the rest of your home folder or start programs.
- **QEMU 11.1.3.** It fixes CVE-2026-93834, which let Linux escape a shared folder, and CVE-2026-17588 in the USB controller.
- **Access to the Mac.** A new section on each VM's page controls what Linux may use on the Mac: services running on the Mac, the clipboard, the microphone, and changing files in the shared folder. Existing VMs keep them all on. Harden turns them all off.
- **Hardened VMs.** New Virtual Machine and Import Disk have a Hardened option, which creates the VM with all of them off. In Terminal, `linuxvmctl create --hardened`.
- **Private copies stay on the Mac.** The shared clipboard no longer sends what password managers mark as private.
- **Safer imports.** Import Disk refuses a QCOW2 disk that refers to other files on the Mac, such as a backing file.
- **Sharing your home folder** now asks first.

The guest tools are unchanged since 0.3.0.
