# Linux VM 0.2.0

- **Automatic updates.** Linux VM now checks for new versions and installs them for you. It asks once whether to check automatically, and Linux VM → Check for Updates… checks right away.
- **Updates wait for your virtual machines.** An update never installs while a virtual machine is running. When one is ready, the window shows an Update button that shuts your virtual machines down and then installs it.
- **Third-party licenses.** Help → Third-Party Licenses lists the open-source software inside the app. Each release's complete source is published next to it.
- **Open source.** Linux VM's own code is public under the MIT License.

Install this version by hand: version 0.1.0 can't update itself. Later versions arrive automatically.
