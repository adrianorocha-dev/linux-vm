# Linux VM 0.2.1

- **Guest tools 0.2.2.** Removing the guest tools from Linux no longer leaves a folder behind. A virtual machine's details show when the disc has a newer version. To update, open the `LINUXVM-TOOLS` disc in Linux, run `sh install.sh` in a terminal there, then log out and back in.

If a virtual machine is running, this update waits for it. The Update button in the Linux VM window shuts your virtual machines down and then installs it.
