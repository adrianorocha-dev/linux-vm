# Linux VM 0.3.0

- **Fedora and KDE Plasma.** The guest tools now support Fedora 44 Workstation, Fedora 45 KDE Plasma Desktop, and KDE Plasma on Ubuntu 26.04 (Kubuntu's desktop). The Guest Tools disc carries a package for Ubuntu and one for Fedora, and `sh install.sh` picks the right one.
- **The shared clipboard works in KDE Plasma**, for text and images, both ways.
- **Shut Down works in KDE Plasma.** With the guest tools, the VM's power button shuts Linux down instead of opening a logout prompt. So Shut Down in the app, and before an update, finishes on its own.
- **The VM's page shows its desktop**, such as GNOME 50 or KDE Plasma 6.8, and whether the shared clipboard works.
- **New VMs are named after their installer image**, such as "Fedora KDE".

To update the guest tools in a VM, open the `LINUXVM-TOOLS` disc in Linux's file manager. In KDE Plasma's Dolphin, click the disc to open it. Run `sh install.sh` in a terminal there, then log out and back in.

Fedora 45 Workstation, with GNOME 51, isn't supported yet: there the shared clipboard is off, and everything else works.
